# 制作优秀 AI 视频的要素清单

按制作阶段排列。✅ 表示工具链已支持，🔧 表示目前靠人工或外部工具，欢迎补充实现。

## 1. 前期：故事与分镜
- ✅ **一句话故事（logline）**：说不清就别开拍。
- ✅ **分镜表**：每个镜头写清楚画面、景别与运镜、光线、氛围、台词（`shots`）。
- **节奏**：短视频前 3 秒要有钩子；单个镜头通常 3–8 秒，信息密度高的镜头更短。
- **景别变化**：远景交代环境 → 中景交代关系 → 特写交代情绪。连续多个同景别镜头会显得单调。
- **超过 15 秒的连续动作**：拆成多段并尾帧接力（✅ 自动）。但接力越多，画面越容易劣化，**超过 2–3 段时应改成切镜**。

## 2. 视觉一致性（最影响观感）
- ✅ **全片风格锁定**：`style.look / palette / lighting` 每次原样拼进提示词。
- ✅ **角色外观锁定**：`characters[].description` 写清年龄、发型、五官、体型和 1–2 个标志性特征（如"右耳缺口"），每次出场原样重复。
- 🔧 **角色设定图**：先生成三视图或表情表，挑出最满意的一张作为参考或首帧来源。
- 🔧 **场景参考图**：同一场景多个镜头时，先定一张"场景母版"。
- ✅ **关键帧先行**：新机位先出静态首帧，人工或 agent 挑选满意后再图生视频。图片便宜，视频贵。
- ✅ **负面约束**：`style.avoid` 列出水印、畸形肢体、闪烁、多余文字等。

## 3. 构图与动作的稳定（复杂镜头）
- ✅ **3D 预演（previs）**：用 Blender 摆好机位、人物站位和姿态，渲染出首帧（`start_frame: file`）。适合多人站位、精确运镜、需要和前后镜头空间一致的场景。见 [3d-previs.md](3d-previs.md)。
- 🔧 **手绘或拼贴分镜**：粗略构图图同样可以作为首帧或参考。
- **一个镜头只做一件事**：动作越简单越稳定。复杂动作要拆成多个镜头。
- **运镜要具体**：写"缓慢推近""固定机位""左向右平移"，不要写"动感镜头"。

## 4. 生成与筛选
- ✅ **断点续跑与指纹**：只重新生成改动过的段落。
- ✅ **重拍保留历史**：`--retake`，旧版本放在 `output/takes/`，方便对比。
- **抽卡**：重要镜头多生成 2–3 次，挑最好的一版。
- **逐段质检**（接力前必须做）：检查脸、手、肢体数量、物体穿模、文字乱码、闪烁、动作是否完成、尾帧是否适合接力（不要停在模糊或运动中的帧）。
- 🔧 自动质检：可以用多模态模型给尾帧和抽样帧打分（待实现）。

## 5. 后期
- ✅ **规格统一**：分辨率、帧率、编码、音轨统一后再拼接。
- ✅ **转场**：`cut` / `fade`。
- ✅ **字幕**：根据台词自动生成 SRT，可选择烧录进画面。
- ✅ **背景音乐**：循环铺底，结尾淡出。
- 🔧 **配音 / TTS**、**音效**、**调色统一（LUT）**、**超分到 1080p/4K**、**插帧到 60fps**、**封面图**。

## 6. 发布
- ✅ 每个平台生成一份标题、简介和标签的元数据（`output/publish/*.json`）。
- 竖屏 9:16 适合抖音、TikTok、Shorts、视频号；横屏 16:9 适合 B 站、YouTube。
- 🔧 自动上传（各平台 API 或浏览器自动化）。
